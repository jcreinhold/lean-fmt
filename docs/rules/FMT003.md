# FMT003 — remove a duplicate import

- **Lifecycle:** stable
- **Category:** `imports`
- **Tier:** `source`
- **Fix:** fixable
- **Default:** on

The same module is imported twice in a header. The safe fix removes the later duplicate line. An exact repeat imports nothing new, so removing it preserves the module's environment and import order.

## Example

Bad:

```lean
import Lean
import Lean
```

Good:

```lean
import Lean
```

## Using this rule

- Select: `--select FMT003` or `--select imports`
- Suppress: `-- lean-fmt: ignore[FMT003]`
