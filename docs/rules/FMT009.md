# FMT009 — report an unclosed section or namespace

- **Lifecycle:** preview
- **Category:** `structure`
- **Tier:** `syntax`
- **Fix:** report-only
- **Default:** off

A `section` or `namespace` is opened and never closed by a matching `end`, tracked as a scope-name stack over the top-level command stream (one `end A.B` closes both a single `namespace A.B` and an `A`/`B` pair). An outermost anonymous `noncomputable`/`public`/`meta` section — the idiomatic whole-file section — is not reported. Report-only: where a scope *should* close is author judgment.

## Example

Bad:

```lean
namespace Demo

def answer : Nat := 42
```

## Using this rule

- Select: `--select FMT009` or `--select structure`
- Suppress: `-- lean-fmt: ignore[FMT009]`
