# FMT001 — reject forbidden control bytes in source

- **Lifecycle:** stable
- **Category:** `security`
- **Tier:** `source`
- **Fix:** report-only
- **Default:** on

A C0 control byte other than TAB or LF, or the DEL byte (U+007F), appears in the source. In accepted Lean these bytes can only survive inside a string literal or a comment — a bare control byte in the command stream is a parse error — so the finding always lands on program data or human-read text. It is report-only: deleting the byte would change that data or text, which no byte-level argument can call safe. Illustrative (the byte cannot be shown verbatim): a string "a<U+0000>b" carrying an embedded NUL is flagged at the NUL.

## Using this rule

- Select: `--select FMT001` or `--select security`
- Suppress: `-- lean-fmt: ignore[FMT001]`
