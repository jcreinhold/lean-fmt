# FMT015 — report an unused variable or binder

- **Lifecycle:** preview
- **Category:** `unused`
- **Tier:** `semantic`
- **Fix:** report-only
- **Default:** off

A bound variable or binder is never used, surfaced from the compiler's `linter.unusedVariables` diagnostic. Report-only: removing or renaming a binder is not an edit any byte-level or projection fact here can prove safe.

## Example

Bad:

```lean
def constZero (x : Nat) : Nat := 0
```

## Using this rule

- Select: `--select FMT015` or `--select unused`
- Suppress: `-- lean-fmt: ignore[FMT015]`
