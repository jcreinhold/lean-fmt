# FMT006 — report an import made redundant by another import's transitive closure

- **Lifecycle:** stable
- **Category:** `imports`
- **Tier:** `source`
- **Fix:** report-only
- **Default:** on

An import is already pulled in by another import's transitive closure, so it adds nothing to the module's environment. Report-only: whether the redundant line documents intent or should be removed is author judgment, and deciding it needs the Lake module graph, not this file alone. Illustrative (needs a multi-module project): importing both a module and a second module that already imports it flags the redundant one.

## Using this rule

- Select: `--select FMT006` or `--select imports`
- Suppress: `-- lean-fmt: ignore[FMT006]`
