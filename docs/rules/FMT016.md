# FMT016 — report a section variable unused in a theorem

- **Lifecycle:** preview
- **Category:** `unused`
- **Tier:** `semantic`
- **Fix:** report-only
- **Default:** off

An automatically-included section `variable` is unused in a theorem, surfaced from the compiler's `linter.unusedSectionVars` diagnostic. Report-only, for the same reason as FMT015.

## Example

Bad:

```lean
section
variable {α : Type} [inst : Inhabited α]
theorem refl_eq (a : α) : a = a := rfl
end
```

## Using this rule

- Select: `--select FMT016` or `--select unused`
- Suppress: `-- lean-fmt: ignore[FMT016]`
