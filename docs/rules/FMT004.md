# FMT004 — report an import made redundant by another import's transitive closure

- **Lifecycle:** stable
- **Category:** `imports`
- **Tier:** `semantic`
- **Fix:** report-only
- **Default:** on

A plain import is covered by another import and has no positive defining-module use in the exact frontend evidence. Direct uses in statements, proofs and definitions retain their defining import. This is a report-only candidate, not a proof that removal is safe: syntax, tactics and command effects may still require it. Missing use evidence requires exact analysis, never an empty use set.

## Using this rule

- Select: `--select FMT004` or `--select imports`
- Suppress: `-- lean-fmt: ignore[FMT004]`
