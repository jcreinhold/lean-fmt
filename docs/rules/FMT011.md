# FMT011 — remove a duplicate deriving class

- **Lifecycle:** preview
- **Category:** `redundancy`
- **Tier:** `syntax`
- **Fix:** fixable
- **Default:** off

A `deriving` clause names the same class twice. The safe fix deletes the later instance and its separator, so `deriving Repr, Repr` becomes `deriving Repr`. Safe for the same idempotence reason as FMT010.

## Example

Bad:

```lean
inductive Color where
  | red
  deriving Repr, Repr
```

Good:

```lean
inductive Color where
  | red
  deriving Repr
```

## Using this rule

- Select: `--select FMT011` or `--select redundancy`
- Suppress: `-- lean-fmt: ignore[FMT011]`
