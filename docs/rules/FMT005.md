# FMT005 — report imports out of the configured import layout's order

- **Lifecycle:** stable
- **Category:** `imports`
- **Tier:** `source`
- **Fix:** report-only
- **Default:** on

Imports are not in the order the configured `[format] import-layout` prescribes: module-name order within each blank-line group under `grouped`, or the canonical layout's order — modifier bucket, then prefix sub-block, then module path — under `canonical`. Report-only: reordering imports can change initialization order in principle, so the reordering is surfaced rather than applied automatically.

## Example

Bad:

```lean
import Lean.Elab
import Lean.Data
```

## Using this rule

- Select: `--select FMT005` or `--select imports`
- Suppress: `-- lean-fmt: ignore[FMT005]`
