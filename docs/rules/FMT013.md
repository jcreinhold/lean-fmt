# FMT013 — remove redundant nested parentheses

- **Lifecycle:** preview
- **Category:** `redundancy`
- **Tier:** `syntax`
- **Fix:** fixable
- **Default:** off

A parenthesized term's only child is itself parenthesized — `((e))`. The inner `(e)` is already a complete atomic term, so dropping the outer pair cannot regroup anything; only the directly-nested case is answered, because the projection carries no precedence. The safe fix deletes the outer pair.

## Example

Bad:

```lean
def twice : Nat := ((1))
```

Good:

```lean
def twice : Nat := (1)
```

## Using this rule

- Select: `--select FMT013` or `--select redundancy`
- Suppress: `-- lean-fmt: ignore[FMT013]`
