# FMT012 — report a development-only set_option left in source

- **Lifecycle:** preview
- **Category:** `debug`
- **Tier:** `syntax`
- **Fix:** report-only
- **Default:** off

A committed `set_option` sets an option whose root is `debug`, `pp`, `profiler`, or `trace` — the set Mathlib's `linter.style.setOption` flags. Matching the `set_option` node (not a string) means a `set_option`-looking string or comment never fires. Report-only: removing a committed option is author intent, and the scoped `… in` boundary is not a byte-safe question.

## Path out of preview

Graduates when it produces at least 10 audited true positives with zero false positives on a corpus with no `set_option` linter of its own. mathlib cannot supply that evidence by construction: `linter.style.setOption` is this rule's near-exact equivalent, so the zero it scored across 85 mathlib modules says what mathlib already enforces and nothing about whether this rule is correct.

## Example

Bad:

```lean
set_option trace.Meta.debug true

def answer : Nat := 42
```

## Using this rule

- Select: `--select FMT012` or `--select debug`
- Suppress: `-- lean-fmt: ignore[FMT012]`
