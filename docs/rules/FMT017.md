# FMT017 — report a bound variable that resembles a nullary constructor

- **Lifecycle:** preview
- **Category:** `naming`
- **Tier:** `semantic`
- **Fix:** report-only
- **Default:** off

A bound variable's name matches a nullary constructor in scope, surfaced from the compiler's `linter.constructorNameAsVariable` diagnostic — a pattern that reads as a constructor but binds a fresh variable. Report-only.

## Example

Bad:

```lean
inductive Light where
  | red
  | green

def f (red : Light) : Light := red
```

## Using this rule

- Select: `--select FMT017` or `--select naming`
- Suppress: `-- lean-fmt: ignore[FMT017]`
