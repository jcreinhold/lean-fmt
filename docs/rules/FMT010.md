# FMT010 — remove a duplicate attribute in an attribute list

- **Lifecycle:** preview
- **Category:** `redundancy`
- **Tier:** `syntax`
- **Fix:** fixable
- **Default:** off

An `@[…]` attribute list names the same attribute twice. The safe fix deletes the later instance and its preceding separator, so `@[simp, simp]` becomes `@[simp]`. Safe: an exact repeat is idempotent, so removing it preserves what the elaborator records.

## Example

Bad:

```lean
@[simp, simp] def idem : Nat := 0
```

Good:

```lean
@[simp] def idem : Nat := 0
```

## Using this rule

- Select: `--select FMT010` or `--select redundancy`
- Suppress: `-- lean-fmt: ignore[FMT010]`
